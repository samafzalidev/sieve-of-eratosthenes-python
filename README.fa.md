## 🧠 الگوریتم چگونه کار می‌کند؟

الگوریتم غربال اراتوستن به جای اینکه هر عدد را جداگانه برای اول بودن بررسی کند، عددهای غیر اول را علامت‌گذاری می‌کند.

در ابتدا فرض می‌شود که همه عددها اول هستند. سپس الگوریتم از عدد `2` شروع می‌کند و همه مضرب‌های هر عدد اول را به عنوان عدد غیر اول علامت‌گذاری می‌کند. در پایان، عددهایی که هنوز به عنوان عدد اول باقی مانده‌اند، همان اعداد اول هستند.

### مراحل الگوریتم

1. یک لیست بولی از عدد `0` تا `limit` ساخته می‌شود.
2. در ابتدا فرض می‌شود همه عددها اول هستند.
3. الگوریتم از اولین عدد اول یعنی `2` شروع می‌کند.
4. همه مضرب‌های عدد اول فعلی به عنوان غیر اول علامت‌گذاری می‌شوند.
5. سپس الگوریتم به عدد بعدی می‌رود.
6. این روند تا زمانی ادامه پیدا می‌کند که `p * p <= limit` باشد.
7. در پایان، عددهایی که هنوز به عنوان اول علامت‌گذاری شده‌اند برگردانده می‌شوند.

## 📥 نصب و اجرا

1. **ریپازیتوری را کلون کنید**

```bash
git clone https://github.com/samafzalidev/sieve-of-eratosthenes-python.git
```

2. **وارد پوشه پروژه شوید**

```bash
cd sieve-of-eratosthenes-python
```

3. **فایل پایتون را اجرا کنید**

```bash
python sieve_of_eratosthenes.py
```

در بعضی سیستم‌ها ممکن است لازم باشد از دستور زیر استفاده کنید:


## 🎮 نحوه استفاده

برای تولید اعداد اول تا یک محدوده دیگر، کافی است مقدار `limit` را تغییر دهید:
